# Kaelixo Typography Responsive Scaling Report

This report outlines the responsive typography sizes implemented across the Kaelixo website. The sizes smoothly scale across devices using a standardized breakpoints system to maintain perfect visual hierarchy on Mobile, Tablet, Laptop, and Large Desktop screens.

---

## Global Breakpoint Guide
- **Default (Mobile):** < 640px
- **sm (Tablet):** ≥ 640px
- **md/lg (Laptop):** ≥ 768px / 1024px
- **xl/2xl (Desktop):** ≥ 1280px / 1536px
- **1920+ (Large Desktop):** ≥ 1920px

---

## Standard Typography Scale

To maintain consistency and professionalism, all sections strictly follow this hierarchical scale:

### 1. Eyebrows (Smallest Labels)
*Used for section indicators like "REAL RESULTS", "AI SOLUTIONS", "READY TO BUILD"*
* **Mobile:** 12px
* **Tablet (sm):** 13px
* **Laptop (lg):** 14px
* **Desktop (2xl):** 15px
* **Large Desktop (1920px+):** 16px
* *Tailwind:* `text-[12px] sm:text-[13px] lg:text-[14px] 2xl:text-[15px] [@media(min-width:1920px)]:text-[16px]`

### 2. Button Texts
*Used for Call-to-Action buttons like "Let's Talk", "Start a Conversation", "Explore AI Solutions"*
* **Mobile:** 13px
* **Tablet (sm):** 14px
* **Laptop (xl):** 15px
* **Desktop (2xl):** 16px
* **Large Desktop (1920px+):** 18px
* *Tailwind:* `text-[13px] sm:text-[14px] xl:text-[15px] 2xl:text-[16px] [@media(min-width:1920px)]:text-[18px]`

### 3. Descriptions & Paragraphs
*Used for main section descriptions and body text*
* **Mobile:** 14px
* **Tablet (sm):** 15px
* **Laptop (lg):** 16px
* **Desktop (xl):** 17px
* **Desktop (2xl):** 18px
* **Large Desktop (1920px+):** 20px
* *Tailwind:* `text-[14px] sm:text-[15px] lg:text-[16px] xl:text-[17px] 2xl:text-[18px] [@media(min-width:1920px)]:text-[20px]`

### 4. Sub-headings & Card Titles
*Used for product names, service cards, or secondary headings*
* **Mobile:** 18px
* **Tablet (sm):** 20px
* **Laptop (md):** 22px
* **Laptop (lg):** 24px
* **Desktop (xl):** 28px
* **Desktop (2xl):** 32px
* **Large Desktop (1920px+):** 36px
* *Tailwind:* `text-[18px] sm:text-[20px] md:text-[22px] lg:text-[24px] xl:text-[28px] 2xl:text-[32px] [@media(min-width:1920px)]:text-[36px]`

### 5. Main Headings (H1/H2)
*Used for primary section headings like "Built Smart, Grown Beyond", "Success Stories"*
* **Mobile:** 28px
* **Tablet (sm):** 32px
* **Laptop (md):** 40px
* **Laptop (lg):** 48px
* **Desktop (xl):** 56px
* **Desktop (2xl):** 64px
* **Large Desktop (1920px+):** 72px
* *Tailwind:* `text-[28px] sm:text-[32px] md:text-[40px] lg:text-[48px] xl:text-[56px] 2xl:text-[64px] [@media(min-width:1920px)]:text-[72px]`
